当前版本为 **0.0.7-test.7（Android 测试版）**，不是 iOS 安装包，也不是纯界面预览包。

- 沿用原连接版应用身份 `studio.hexing.shensi.mobile.test` 与固定签名，版本序号从 6 增加到 7。
